## 1. 预注册规则（§13 原文）

```
若控制逐类 recall 变化后 CPD 仍有增量解释力
    → CPD 可作为机制性量，但仍不得表述为因果
若增量解释力消失
    → CPD 只能作为描述性刻画
      · 不得写成独立机制
      · 贡献 2（机制证据）降级为"失效模式的结构化描述"
      · 论文主线转向贡献 3（部署方法）
```

观测量（§13）：增量 R²（环境聚类 bootstrap 区间、效应量）与按环境聚类的交叉验证预测误差改善。

## 3. 判定

### 3.1 `CPD_y`：增量解释力消失 → 走降级分支

三条证据同向：ΔR² = +0.0066（f² = 0.008，不足 Cohen small 阈值 0.02 的一半）；
标准化 β 的环境聚类区间跨零（[−0.757, +0.320]）；样本外 LOEO-CV 预测误差**变差** 4.6%
（两种聚合口径一致）。控制逐类 recall 变化后，`CPD_y` 对 Stacking gain 没有增量解释力。

连同 §2.3/§4.3 已有的代数耦合约束，正文中 `CPD_y` **一律只作描述性刻画**，
不得写成"控制任务难度后仍能解释集成失效"的量。
§5 假设 **H2 的判否条件（"E2 中 CPD 增量解释力消失"）在 `CPD_y` 上触发**。

### 3.2 `CPD_dir`（lenient primary，n=119）：稳健的条件关联，但不满足"机制性量"门槛

样本内：ΔR² = +0.0748（f² = 0.091，small–medium），β = −0.296、区间 [−0.556, −0.175]
不跨零——条件关联稳健。样本外：LOEO-CV 误差不改善（+3.9%），增量不跨环境转化为预测力。
§13 强分支的两条观测量只满足其一，**判定不进入"可作为机制性量"分支**；
如实保留的表述是：`CPD_dir` 与 Stacking gain 存在**控制 recall 变化后的描述性条件关联**
（非机制、非因果、无样本外预测增益、覆盖 119/150 且缺失非随机）。

### 3.3 综合：走 §13 降级分支

1. CPD 不写成独立机制；
2. **贡献 2 降级为"失效模式的结构化描述"**，`CPD_dir` 的条件关联作为该描述的一部分，
   引用时必须携带 3.2 的全部限定与 strict 变体并列数值（v1.3 透明度声明）；
3. **论文主线重心转向贡献 3（部署方法）**——G0 网格的 OOF/UDS 资产与 D8 投票基线已就位，
   G1（9/14 决策门）照常推进，其五项判据不受本判定影响；
4. H2 强形式不成立，如实写入正文/Discussion，不隐藏。

## 4. 敏感性中的重要事实（描述性，进方法学讨论）

**A 臂 DV（历史随机 OOF 口径）下"增量解释力"大得多**：M1 ΔR² = +0.267、M2-lenient = +0.482
（primary 口径下分别为 +0.007 / +0.075）。即：若沿用历史 OOF 口径，本实验会"确认"CPD 的
解释力；诚实的 §9.1 分组口径下它大部分消失。这与 E1 的方向一致——旧口径不仅掩盖崩溃幅度，
也**抬高了 CPD 与 gain 关系的表观强度**。该事实作为 OOF 构造重要性的证据进正文，
**不得**反过来引用 A 臂数字支撑机制主张。
其余敏感性同向：random 参照下 M1 = +0.0095（M2-lenient +0.115，n=94）；
三基模型均值 recall 下 M1 = +0.0002。

## 5. 限制

- 6 个目标环境：LOEO-CV 与聚类 bootstrap 分辨率有限；+3.9%/+4.6% 的误差变化含噪声，
  但方向上确非"改善"；
- DV（B 臂 gain）内含 E1_CONCLUSION §5.2 所述分组 OOF 构造性成分，M0 未控制该成分，
  对 CPD 系数的偏置方向未知；
- `CPD_dir` 覆盖 119/150（§4.3 n_err≥20 准入），缺失集中于低误差参照，非随机；
- 网格任务非独立样本（§8.6/§15）：本判定不依赖显著性检验，全部为效应量 + 区间陈述，未报 p 值；
- 判定基于单一测试床与 3 种漂移类型；UNSW 检验（§16.4）不承担挽救本判定的职能。
