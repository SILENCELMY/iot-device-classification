## 1. 结论摘要

> **原结论「统计显著」不成立。方向（负相关）较稳健，但幅度与显著性由单个任务支配。**
> 按协议 §2.3 与 §11，该结果**降为探索性结果**。预注册的降格判断得到证实。

| 检验 | 结果 | 判定 |
|---|---|---|
| 全样本 Pearson | `r = -0.6295`, `p = 0.0379` | 名义显著 |
| 全样本 **Spearman** | `ρ = -0.5000`, `p = 0.1173` | **不显著** |
| 置换检验 | `p = 0.0285` | 名义显著 |
| Leave-one-task-out | 11 次中仅 **3/11** 仍 `p<0.05`；`r ∈ [-0.9040, -0.3666]` | **不稳健** |
| 去掉 `loro_R2_R4_to_R3` | `r = -0.3666`, `p = 0.2974` | **显著性消失** |
| Leave-one-environment-out | `r ∈ [-0.9433, -0.3085]`；**0 次符号反转** | 方向稳健，幅度不稳健 |
| 按测试环境聚类 bootstrap | 95% CI `[-0.9696, -0.0839]`，不覆盖 0；99.71% 为负 | 方向稳健，上界贴近 0 |
| 口径敏感性 | 0.801 口径 `r=-0.63`；废弃六环境口径 `r=-0.21 (p=0.54)` | **口径依赖** |

## 2. 为什么不稳健：gain 分布由一个极端点支配

11 个任务的 `gain_absolute` 分布（按 gain 升序）：

| 任务 | `cpd` | `gain_absolute` |
|---|---:|---:|
| **`loro_R2_R4_to_R3`** | **0.8014** | **-0.069334** |
| `position_R2_R3_R4_to_R5` | 0.5328 | -0.033393 |
| `loro_R3_R4_to_R2` | 0.3170 | -0.019264 |
| `jitter_R2_R3_R4_to_R6` | 0.3561 | -0.005299 |
| `joint_R2_R3_R4` | 0.0000 | -0.003017 |
| **`loro_R2_R3_to_R4`** | **0.8359** | **-0.002783** |
| `single_round_R4` | 0.0628 | -0.001936 |
| `single_round_R3` | 0.1273 | -0.001815 |
| `single_round_R2` | 0.1179 | -0.001671 |
| `jitter_R2_R3_R4_to_R7` | 0.2184 | -0.001528 |
| `jitter_R2_R3_R4_to_R6_R7` | 0.2815 | -0.000115 |

- gain 全域 `[-0.069334, -0.000115]`；
- **剔除最负点后**收缩到 `[-0.033393, -0.000115]`；
- 最负点是次负点的 **2.08 倍**。

Pearson 对这种"一个远离簇的点"高度敏感。**Spearman（秩相关）不显著（p=0.1173）正是该现象的诊断**：
一旦只看秩序、不看幅度，关系就不成立了。

原报告**确实并列报告了** Spearman `ρ=-0.500, p=0.1173`（`CONTROLLED_CPD_MECHANISM_VALIDATION_FINAL.md`
第 23、141 行）——问题不在于漏报，而在于**结论层的取舍**：第 22、303 行的结论句以 Pearson 的
p=0.0379 断言「统计显著」，未说明同一数据的秩相关并不显著。两个不一致的检验结果并存时，
结论应取更保守的那个，或明确说明分歧来源（本例即"幅度 vs 秩序"）。

### 2.1 更关键的问题：两个高 CPD 任务的 gain 差 25 倍

| 任务 | `cpd` | `gain_absolute` |
|---|---:|---:|
| `loro_R2_R3_to_R4` | **0.8359**（最高） | **-0.002783** |
| `loro_R2_R4_to_R3` | 0.8014 | **-0.069334** |

两者 CPD 几乎相同（0.836 vs 0.801，差 4%），gain 却差 **24.9 倍**。这直接说明：

> **在本数据上，高 `CPD_y` 并不能可靠预测 Stacking gain 崩溃。**

leave-one-task-out 的两个极端正好来自这一对：

- 去掉 `loro_R2_R4_to_R3`（崩溃点）→ `r = -0.3666` (p=0.2974)，关系瓦解；
- 去掉 `loro_R2_R3_to_R4`（反例点）→ `r = -0.9040` (p=0.0003)，关系急剧强化。

**相关系数的大小基本由"保留这两个任务中的哪一个"决定。** 原报告第 6.1 节（第 254-261 行）
已把 `loro_R2_R3→R4` 标为"异常点"（`CPD = 0.836 最高，但 Gain = -0.0028 很小`），
并自注"需要进一步分析：查看 R4 的 error correlation 是否异常低"——即该反例当时已被记录为未决问题，
但 r=-0.630 仍被保留为主证据。本分析量化了这个未决问题的代价：它足以决定结论的显著性。

## 3. Leave-one-task-out 完整结果

按剔除后 `r` 排序（`results/p0_audit/r630_leave_one_task_out.csv`）：

| 剔除的任务 | 测试环境 | 剔除点 gain | `r` | `p` | `p<0.05` |
|---|---|---:|---:|---:|---|
| `loro_R2_R3_to_R4` | R4 | -0.002783 | -0.9040 | 0.0003 | 是 |
| `jitter_R2_R3_R4_to_R6` | R6 | -0.005299 | -0.6373 | 0.0475 | 是 |
| `loro_R3_R4_to_R2` | R2 | -0.019264 | -0.6347 | 0.0487 | 是 |
| `jitter_R2_R3_R4_to_R6_R7` | R6+R7 | -0.000115 | -0.6313 | 0.0503 | 否 |
| `joint_R2_R3_R4` | R2+R3+R4 | -0.003017 | -0.6268 | 0.0525 | 否 |
| `jitter_R2_R3_R4_to_R7` | R7 | -0.001528 | -0.6213 | 0.0552 | 否 |
| `single_round_R4` | R4 | -0.001936 | -0.6164 | 0.0577 | 否 |
| `single_round_R3` | R3 | -0.001815 | -0.6155 | 0.0582 | 否 |
| `single_round_R2` | R2 | -0.001671 | -0.6150 | 0.0585 | 否 |
| `position_R2_R3_R4_to_R5` | R5 | -0.033393 | -0.6019 | 0.0656 | 否 |
| **`loro_R2_R4_to_R3`** | **R3** | **-0.069334** | **-0.3666** | **0.2974** | **否** |

**仅 3/11 次剔除后仍达 p<0.05。** 其中 2 次（`jitter_*_R6`、`loro_R3_R4_to_R2`）的 p 值
为 0.0475 / 0.0487，紧贴 0.05；另外 3 次为 0.0503 / 0.0525 / 0.0552，紧贴另一侧。
**结论对 α=0.05 这条线本身极度敏感**，这类"擦线"结果不应写成"统计显著"。

> 本结果与 `docs/论文冲刺计划_v2.md` 第 30-32 行的手算一致
> （手算「留一后 r 从 −0.630 掉到约 −0.36（p≈0.3）」→ 本次精确值 `-0.3666 / p=0.2974`）。
> V2 审计的这一判断成立。

## 4. Leave-one-environment-out（协议 §15.5）

按测试环境剔除（涉及该环境的所有任务一并剔除）：

| 剔除环境 | 剔除任务数 | 剩余 n | `r` | `p` |
|---|---:|---:|---:|---:|
| R2 | 3 | 8 | -0.6201 | 0.1010 |
| R3 | 3 | 8 | **-0.3085** | 0.4572 |
| R4 | 3 | 8 | **-0.9433** | 0.0004 |
| R5 | 1 | 10 | -0.6019 | 0.0656 |
| R6 | 2 | 9 | -0.6408 | 0.0630 |
| R7 | 2 | 9 | -0.6219 | 0.0737 |

- **符号反转次数 0** —— 负方向在环境层面稳健；
- 但 `r` 跨越 `[-0.9433, -0.3085]`，**幅度完全不稳定**；
- 去掉 R3（含崩溃任务 `loro_R2_R4_to_R3`）后 p=0.4572，去掉 R4（含反例任务）后 p=0.0004。
  再次印证 §2.1：R3 与 R4 这两个环境把结论推向相反方向。

协议 §18 的触发信号「去掉一个环境后 CPD-gain 关系方向反转」**未触发**（0 次反转）。
但幅度的不稳定性本身足以支撑降格。

## 5. 按测试环境聚类的 bootstrap（协议 §15.1、§15.6）

聚类单位 = **测试环境**（协议 §15.1）。共 8 个簇：

| 簇 | n | 任务 |
|---|---:|---|
| R2 | 2 | `single_round_R2`, `loro_R3_R4_to_R2` |
| R3 | 2 | `single_round_R3`, `loro_R2_R4_to_R3` |
| R4 | 2 | `single_round_R4`, `loro_R2_R3_to_R4` |
| R5 | 1 | `position_R2_R3_R4_to_R5` |
| R6 | 1 | `jitter_R2_R3_R4_to_R6` |
| R7 | 1 | `jitter_R2_R3_R4_to_R7` |
| R2+R3+R4 | 1 | `joint_R2_R3_R4` |
| R6+R7 | 1 | `jitter_R2_R3_R4_to_R6_R7` |

结果（有效重抽样 10000/10000，无退化）：

| 量 | 值 |
|---|---|
| 95% CI | **`[-0.9696, -0.0839]`** |
| 中位数 `r` | `-0.6341` |
| `r < 0` 的比例 | `0.9971` |
| 是否覆盖 0 | **否** |

**如何读这个区间——三点限制，不得只报"不覆盖 0"**：

1. **区间极宽**：`[-0.97, -0.08]` 几乎横跨"几乎完美负相关"到"几乎无关"。它排除的只是
   "严格为 0"这一点，对效应量几乎没有约束力。
2. **上界贴近 0**（-0.0839）。结合 8 个簇中有 **5 个是单任务簇**，该区间的名义覆盖率不可靠。
3. **协议 §15.7 的额外限制**：混淆矩阵由约 380 个高度自相关的 10 秒窗口估出，有效精度低于
   `n=380` 所示。本区间未对该自相关做任何校正，因此实际上**偏窄**（过于乐观）。

因此本节**不构成对原结论的支持**。它只支持一个弱得多的陈述：*该关系的方向在环境重抽样下
倾向为负*。

## 6. 口径敏感性

同样 11 个任务、同样的 `gain_absolute`，只更换 CPD 口径：

| CPD 口径 | `r` | `p` |
|---|---:|---:|
| **0.801 口径**（基准 = `joint_R2_R3_R4`） | `-0.6295` | `0.0379` |
| **废弃六环境口径**（v2） | `-0.2065` | `0.5424` |

原结论 `r=-0.630` **只在 0.801 这一个口径下成立**。换用 v2 的六环境 pairwise 口径，
相关性掉到 -0.21、p=0.54，完全不显著。

注：六环境口径本身已按协议 §4.4 废弃（矩阵不同质，见 [CPD_DEFINITIONS.md](../../docs/CPD_DEFINITIONS.md) §5.2），
因此这里**不是**"两个口径谁对"的问题——而是说明：原结论的显著性不是一个口径无关的事实。
选择口径的自由度必须在内层完成（协议 §8.3 禁止 selection-on-test）。

## 7. 按协议规定的处置

协议 §2.3 与 §11 已预注册处置方式，本分析结果与之一致，无需修改协议：

| 协议条款 | 要求 | 本分析是否支持 |
|---|---|---|
| §2.3 | 「既有 `r=-0.630` 受单个任务影响且未达显著，**只作探索性结果**」 | **支持**。受 `loro_R2_R4_to_R3` 单点支配；Spearman 未达显著 |
| §11 | 「做 leave-one-task-out 与按环境聚类 bootstrap，结论如实记录，在正文降为探索性结果」 | **已完成**，结论如实记录于本文档 |

### 7.1 正文写法建议（不得超出证据）

**可以写**：

- 在 11 个任务上观察到 `CPD_y` 与 Stacking gain 的负向关联（Pearson `r=-0.63`），
  但该关联**由单个任务支配**：剔除 `loro_R2_R4_to_R3` 后 `r=-0.37`（p=0.30），
  且秩相关本身不显著（Spearman `ρ=-0.50`, p=0.12）。
- 按测试环境聚类的 bootstrap 95% CI 为 `[-0.97, -0.08]`，区间极宽，仅提示方向倾向为负。
- 两个 CPD 近乎相同（0.84 / 0.80）的任务 gain 相差约 25 倍，说明**`CPD_y` 单独不足以预测
  Stacking 失效**。

**不得写**：

- ❌「统计显著」「显著负相关」（Spearman 不显著；留一后 p=0.30；p 值擦线）
- ❌「CPD 越大 gain 越低」作为一般规律（§2.1 的反例直接否证）
- ❌ 任何因果表述（协议 §「冻结条款」：相关性结论一律不得表述为因果）
- ❌ 把 `n=11` 当作独立样本做显著性推断（协议 §15.2、§2.3：六次采集重组出的任务不独立）

### 7.2 对下游实验的影响

1. **强化了 E2 的必要性**（协议 §13）。§2.1 的反例（同 CPD、gain 差 25 倍）正是 E2 要区分的
   竞争解释：CPD 可能只是"目标环境本身更难"的**描述**而非**机制**。
   E2 的 M0（逐类 recall 变化）很可能已能解释 `loro_R2_R4_to_R3` 的崩溃
   （该任务 Sensor 召回降至 18.7%，见协议 §13）。
2. **强化了 E1 的必要性**（协议 §12）。整个 `r=-0.630` 建立在 `loro_R2_R4_to_R3` 的
   `gain=-0.0693` 上，而 E1 正是要检验这个旗舰崩溃值是否依赖错误的 OOF 划分。
   **若 E1 的 B 臂使该崩溃消失，`r=-0.630` 将同时失去其唯一支撑点。**
3. **不要把 `r` 作为 H2 的主证据**。H2 的判否条件在 E2（增量解释力），不在这个相关系数。
