## 0. 一句话

已有工作把跨环境泛化当作**全局**特征/模型选择问题。我们发现失效不是方差而是
**确信地判错**、且**集中在极少数类对**上；据此给出一个**逐类对**的诊断与干预程序，
并在一个从未读取过的 16 天保留集上做了**预登记的一次性确证**。

---

## 1. 问题与立场

设备识别模型在源环境训练、目标环境部署时精度大幅下降。主流解法是选一组
"更鲁棒"的全局特征/模型（如 GeMID 用遗传算法在多个跨环境组合上选特征取交集）。

我们的立场不同：**不存在单一正确的特征集**，该用哪些取决于**是哪一对类**、
以及**在什么判决粒度上**。因此方法不是"选一组特征"，而是
**逐类对的候选配置验收程序 + 安全施加机制**。

**评价口径（重要）**：窗口级 macro-F1 为主判据，设备级只并报。
但 macro-F1 本身会稀释——一个类对的彻底翻转在 29 类里只体现为 +0.0075。
故**逐类对的数与端到端的数必须并报**，不允许只报好看的那个。

## 3. 四条主张与证据

### C1 失效是"确信地判错"，且集中在极少数类对

不是模型犹豫，是**系统性地把 A 映到 B**。五处独立出现：

1. stacking 崩溃：元模型学到错误的跨类映射（grouped OOF 下 macro 0.5455→0.4907）
2. 反转类对：跨环境 AUC 降到 0.01（比随机差，即方向翻转）
3. 自采 `Light_T1|Sensor` 在位者最低 0.0029
4. CIC 对内准确率 0.21（低于随机）
5. **最极端一处（本次新增）**：CIC `GlobeLamp|GosundSocket`，凡真类属于该对的窗，
   模型 top-1 **从来不是对内另一个，而是第三类**

**错误集中度（且不随特征增强而改变）**：
```
UNSW  45 对中 1 对扛 88.2% 错误（BelkinWemoMotion|BelkinWemoSwitch）
CIC   前 3 对占 68.5%，且全部落在同一指纹组内
补上包长直方图族后：UNSW 前 6 对 68.9% → 69.2%，主错误对 1318 → 1327（不降反升）
```

### C2 两型难度，且可用"粒度饱和曲线"事前区分

```
方差型   证据增多即溶解，曲线饱和于 1.0        UNSW
身份型   曲线饱和在 1.0 以下，聚合无效         CIC
```

**16 天保留集上的实测曲线**（因果计数聚合 + Hellinger + kNN(5)，每 10 秒一判决）：

| k | 标称证据 | **实测跨度中位** | macro-F1 | 错误数 | Belkin 对占错误 |
|---|---|---|---|---|---|
| 1 | 10 s | 10.0 s | 0.7943 | 112222 | 31.3% |
| 3 | 30 s | 33.9 s | 0.9432 | 27596 | 91.8% |
| 6 | 60 s | 72.2 s | 0.9844 | 7914 | 75.9% |
| 10 | 100 s | 130.0 s | 0.9928 | 3719 | 57.4% |
| 30 | 300 s | 404.0 s | 0.9976 | 1531 | 2.1% |

CIC 同法：0.5268 → 0.8172 后**饱和**（600s→1200s 反而回落到 0.8126）；
独立路径的块聚合在 CIC 上 300s 0.8209 → 2400s 0.8222，**同处饱和** ⇒
饱和是数据的性质，不是聚合方式的。

**⚠ 口径**：`k` 数的是"最近 k 个**已观测**窗"，少于 2 包的窗被丢弃，
故标称 100 s 实为中位 130 s、p90 308 s。**报实测跨度，不报 k×10s。**

见 §4、§5。

### C4 不可区分能被检出并给出证据

**D-Link：8 台同型号摄像头**
```
全体 macro-F1 = 0.2803                        聚合指标看不出异常
逐对【严格双峰】8 对 ≈0.50 / 8 对 ≈0.77        提示隐结构
隐簇 X={Cam1,2,4,5} Y={Cam3,6}，不跟批次/MAC 段走
特征层：len_max  X=263 / Y=262                差【1 字节】
原始包：三种周期包（各 960 次/天）各短 1 字节   312/331/347 → 311/330/346
真因：IP 地址【字符串长度】
      X  .170 .194 .241 .211 → 14 字符
      Y  .56  .55           → 13 字符
```
设备把自己的 IP 以字符串嵌在 SSDP/UPnP 消息里。**扣掉该人工产物后，
同型号可分性是精确 0.50**（8 对 0.4942–0.5162；专用二分类器一分不多，
排除多类竞争解释；**阳性对照**：跨型号 12 对 0.878–0.893）。

这是一类**间接泄漏**：不读该字段也会中招，故对**任何基于包长的方法**同样成立
（含 ByteIoT 那一族）。**检查方法**：可分性是否跟着自指串长度走。

**三个数据集，三种"数据以错误的理由支持了这个区分"**：
```

                       同批数据只改标签空间：跨日 0.6074 → 0.9181

```

## 4. 方法（最终形态，即被确证的那一个）

```
第一段  证据聚合
        管线形态：因果概率平滑（按物理流 MAC 分组，k 在选参天上选）
        诊断形态：因果计数聚合（窗 n 用 [n−k+1,n] 的计数【相加】）
        —— 两者是不同仪器，不可混报（见 §7 局限）

第二段  逐类对配置推导 + 不伤闸门
        候选空间：族掩码(14) × 模型{lr, rf} × 区{R2, R3∩R1, R3}
        区定义    R2 = {top1,top2}={i,j}
                  R3 = {i,j} ⊆ top-3
                  R3∩R1 = R3 且 top1∈{i,j}
        闸门      【整区记账】：在位者与候选在【闸门实际作用的全部窗】上量，
                  要求 候选 > 在位者 + 0.02
        算子      【等权融合】pred = argmax(0.5×基模型(限制到{i,j}) + 0.5×专用二分类器)
                  w 固定 0.5，【不进搜索空间】
```

**三处修正的来历（全部在读保留集之前，理由与证据记于协议 §8/§9）**：

1. **整区记账**。原实现在 `真类∈{i,j}` 的窗上量收益、却对整个区施加。
   R3 含真类为第三类的窗；模型正靠第三类判对时，翻成 i 或 j 就把对的改错了，
   而闸门看不见。实测 Belkin 区上 +0.18 而端到端 **−0.0085**。
   修正后，两个数据集 16 个案例中放行/拒绝与端到端符号**零分歧**。

2. **区进入搜索空间**。`R3∩R1` 不能作全局区：CIC `GlobeLamp|GosundSocket` 在其下
   **真类属于该对的窗为 0 个**，战果（+0.0163）被砍光。最优区因对而异。

3. **等权融合替代硬替换**（最重要）。轻度验证显示唯一过闸的对符号翻转
   （选参天 +0.0996 → 施加天 −0.0237）。诊断发现**修复本身很稳**
   （0.6093 vs 0.6068），变的是**在位者**（0.5097 → 0.6304）：
   ```
   w        16-09-30   16-10-11   16-10-12
   0.00       0.5112     0.6302     0.6339   纯基模型
   0.50       0.5756     0.6807     0.6771   ← 三天同时最好
   1.00       0.6093     0.6054     0.6091   纯专用 = 硬替换
   在位者      0.5097     0.6294     0.6322
   ```
   ⇒ 专用二分类器**确实带来基模型没有的信息**，硬替换把基模型的一并扔了。
   **`w` 不可单天调**：选参天最优是 w=1.0，恰是施加天最差的。故固定等权。

## 6. 支撑性发现

### 6.1 UNSW 全类对账本：靶为空

C(10,2)=45 对全部过账（outer=16-10-12）：
```
                                       错    错占比    对内     上界(同口径)
BelkinWemoMotion|BelkinWemoSwitch    1334   88.2%   0.6585   0.6656   ← 唯一未解
NetatmoWeather|NetatmoWelcome          89    5.9%   0.9785   0.9682   ← 上界低于现状
AmazonEcho|NetatmoWeather              25    1.7%   0.9804   0.9679   ← 同上
其余 42 对                            ≤11    4.2%   ≥0.95    ≥0.95
```
**不存在"可分但未解"的对。** 唯一未解那对在 10 秒窗上上界 ≈ 现状，
但在 **100 秒证据下完全可分**（错 1391 → 9）
⇒ **「不可分」必须标注证据时长**，不能只相对于特征空间。

### 6.2 分布形状类特征族的有效性由**窗内包数**决定，可事前算

困扰整日的现象：帧长直方图族（69 列）在自采 **+0.1008**、在 UNSW/CIC **≈0**。
量出机制：

```
数据集   包数_p10  包数_中位  包数_p90   非零箱_中位  占用率   仅≤1箱的窗占比
自采        8.0     28.0     85.0        5.0     15.6%      5.5%
UNSW        2.0      4.0     20.0        1.0      3.1%     53.5%
CIC         2.0      3.0     14.0        2.0      6.2%     25.4%
```
**UNSW 过半的窗填不出 2 个箱** —— 直方图退化为孤立计数，无分布形状。
且**困难对恰是最稀疏的**：UNSW Belkin 非零箱 1.02/1.03；
CIC Teckin/Yutron 1.21–1.23（唯一修不动的那对）。

**与聚合闭合**：UNSW k=6 有效包数 ≈24 → 0.9844，与自采单窗 28 包 → 0.9082 同量级。
⇒ 聚合起作用的机制**就是把直方图填满**。

⇒ **"候选特征族在某粒度上能否使用"可在训练前计算，不必试。**

### 6.3 结构还原（三条独立轴，每条有外部真值）

## 8. 局限（自陈）

1. **两臂未统一**。诊断跑在 kNN + Hellinger 包长分布上，部署跑在 RF + 130 列上。
   诊断对部署的有效性**未验证**。原因：61 个基特征含分位数/矩/间隔统计，
   **不能靠平均已算好的分位数聚合**；统一需保留每包 (时间戳,长度,方向) 并重算全部量。
2. **自采用不了第一段**。网关三类共用一个 MAC，因果聚合在该层非法。
   即**唯一的空口数据集恰是主方法用不上的那个**，须正面回答。
3. **有效样本量被高估**。k=10 时相邻窗共享 9/10 的包，测试窗高度相关；
   故 C3a 只判饱和水平，不判显著性。
4. **第二段的端到端增益小**（+0.008）。依赖"换正确分母"的论证承重，
   该论证必须由 §6.1 的账本支撑，否则会被读作挑选有利类对。
5. **逐对账本只做了 UNSW**（45/45）。CIC 只审过前 6–8 对，自采未做。
   主张覆盖四个数据集，此项证据只覆盖一个。
6. **自采规模小**（11,303 窗 / 5 类），且为单人一个月采集。
   作为唯一空口数据集有其价值，但不足以单独支撑跨环境结论。

### 11.1 落差是阶梯不是悬崖，而"没见过这个轮次"占了绝大部分

自采 full94、5 种子均值：
```
同轮次随机划分     0.9622        逐级差
同轮次时间块       0.9296        −0.033  轮内时间漂移（R4 独占 −0.073）
联合三轮内部       0.9200        −0.010  混入另外两轮
联合三轮时间块     0.8936        −0.026  联合的轮内漂移
跨轮次 LORO        0.6979        −0.196  ← 悬崖：从未见过这个轮次
```
前三级合计 −0.069，最后一级 −0.196。
⇒ **"同轮次 90+"的主要成分不是时间稳定性，是"见过这个轮次"。**
这条独立支持 C1：失效不是渐变的噪声累积，而是遇到未见环境时的**结构性**判错。

### 11.2 stacking 低于它自己的最佳基模型（追因的起点）

9 个跨轮次任务 `gap_vs_best_base` 均值 **−0.0961**
（`|S|=2` 三任务 −0.1741、`|S|=1` 六任务 −0.0571）。
元模型学到的是**错误的跨类映射**，不是权重给错 —— C1 的第一处出现。

### 11.3 容量不解决跨环境失效（2026-07 深度模型实验的净结论）

四个深度模型（Multi-Scale Residual CNN / Temporal Dilated Residual CNN /
Lightweight Feature Transformer / Attention-Pooled Feature Transformer）与 RF 对比，
结论是：**更强的表示学习不蕴含更强的拓扑鲁棒性**；
增强的全局关系建模抬高同分布精度，代价是更大的环境特异拟合。

⇒ 与 [[always-RF]] 一致：**RF 是本实验测出的最优解，不是待打败的文献基线。**
⇒ 这条使"加大模型"这条路线可以在论文里被**实测排除**，而不是靠断言排除。

### 11.5 搬流程，不搬答案

**不需要找一个跨数据集通用的特征集。** 每个数据集用同一套流程得到**自己的**答案，
只比较"它自己有没有变好"。

支持这条的实测：自采与 UNSW 的 61 列**在构造上不可通约** ——
34/61 的分布重叠 <0.20，`interarrival_p10` 相差 **13,700 倍**。

⇒ 由此，"没有公开的 802.11 数据集"只挡住**发现**的复现，**挡不住流程的复现**。

   自采 94 列 → 10 组，UNSW 62 列 → 7 组，本文 130 列 → 14 组。
