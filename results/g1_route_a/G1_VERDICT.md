## 2. 失败的性质（决定路线 B 怎么设计，非事后开脱）

1. **不是外层泛化失败，而是选择器家族的容量/信号问题**：各 fold **内层最优** regret 为
   0.0081–0.0238（R3 0.0081、R5 0.0156、R6 0.0185、R4 0.0216、R7 0.0219、R2 0.0238），
   即使在**样本内**，UDS 单调双阈值家族也有 5/6 个 fold 达不到 0.01。阈值网格每 fold 4830 点、
   无一并列歧义（`tiebreak` 均在前两级解决），不存在搜索不足。
2. **选择器的偏离多数是有害的**：相对 always-RF，逐任务 8 胜 16 负；125/150 任务选 RF，
   R6 fold 外层一个非 RF 都没选（该环境上选择器 ≡ always-RF）。
3. **可改进空间确实存在，但 UDS 排不出来**：oracle（三候选事后最优）分布 RF 63 / soft 49 /
   stacking 37 / 并列 1——非退化，且 oracle 平均 F1 高于 always-RF。**头顶空间是真的，
   UDS 抓不住它**——这是 H3/H4 的直接否证，也是本判定最有信息量的部分。
4. **candidate 差距的复现界问题不是失败原因**：所选变体下 top-2 差 < 2e-3 仅 10/150，
   且条件 1–3 的失败幅度（+0.0147 / +0.0061 / +0.0044）均远超 2e-3 复现界。

## 3. 假设与贡献的连带处置

- **H3（UDS 样本外预警）判否条件"G1 未通过"触发**；**H4（选择器降低 regret 且不退化为永远选 RF）**
  失败于"降低 regret"这一半（第 3 条），退化解一半（条件 4）反而通过——如实并列写入。
- 贡献 3 的形态由"UDS 驱动的选择器"改为 **§17.3 路线 B：环境稳健的加权聚合**（单一支线，
  权重由源环境内层验证 + 向均匀权重收缩确定，通过线 = 平均 macro-F1 ≥ RF − 0.005、
  最差环境 F1 高于原始 Stacking、多数外层环境正增益）。
- 与 E2 判定合并后的论文形态（§2.3 已预写）：**失效模式的结构化描述 + 稳健聚合方法**，
  两次降级都走了预注册分支，不是临时改口径。
- UDS 不因本判定被废弃：其无泄漏性质与逐任务数值已落盘，作为"我们试过的无标签代理达不到门槛"
  的负结果证据（X3 的诚实结果），并为路线 B 的**对照**保留。

## 4. 移交路线 B 的可用事实（来自 D8/G1 落盘，非新实验）

- 固定策略基线（环境等权 regret）：always-RF **0.02025** / always-soft-voting 0.04593 /
  always-Stacking 0.07925。**路线 B 的实际竞争对手是 always-RF**，这比协议通过线
  （RF − 0.005）所暗示的更严苛，须在路线 B 规格里写明。
- always-RF 的最差环境 regret = 0.03182（R6），路线 B 的最差环境目标应以此为参照。
- D8 事实：校准 soft voting 在 |S|≥2 上一致优于 Stacking，lgb/xgb 的源域 OOF 系统性过自信
  （T 中位 5.24 / 2.63）——温度校准是路线 B 权重估计的现成输入。

## 5. 限制

- 6 个外层环境、150 个非独立任务（§8.6/§15），本判定为门槛比较，不含显著性检验、未报 p 值；
- 候选集固定为 RF / Stacking / soft voting（§17.1），本判定不覆盖"其它候选下 UDS 是否可用"；
- 选择器家族为单一预注册家族（UDS 单调双阈值），未做家族购物——因此本判定否证的是
  **该家族 + 该候选集**，不是"任何无标签代理都不可能工作"，正文措辞须严格限定在此范围。
