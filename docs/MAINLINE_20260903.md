## 0. 一句话

跨轮次识别率下降不是一个失效，而是**三个**，其中两个可诊断；诊断都是数据集内的无量纲量，
所以**流程可以跨数据集搬，答案不能**——每个数据集得到自己的答案，这是唯一干净的外部检验方式。

## 3. 三种失效模式与损伤归因

```
窗口
├─ 基模型自己就错                          ← 模式一：表示层
├─ 基模型一致且正确，元层推翻它              ← 模式二：元层·映射
└─ 基模型意见分歧，元层仲裁选错              ← 模式三：元层·仲裁
```

**模式一 · 表示层（探索性）**：源域拟合的多变量类对判别，CV AUC 0.93–0.98，目标域 0.62–0.68；
39 个困难簇组合中 **13 个目标 AUC < 0.5**（边界反号，最低 0.0000）；易类对 5/5 组合 1.0000 → 1.0000、零反转。
`auc_tgt → 基模型错误率` **−0.554**（四分位 0.7207 → 0.5410 → 0.3846 → 0.3832 单调）；
`auc_tgt → 元层损伤率` **+0.078**（无）。

**模式二 · 元层·映射（探索性）**：共识推翻率——三基模型一致且正确的窗口中 stacking 改判的比例。
三旗舰任务 **1149/1472 = 78.06%**，易类 **0/2101**。
**易类/Socket 免疫的一条已知限定（`PROJECT_STATUS_FOR_EXTERNAL_REVIEW_20260902` §6.2 已记「待查」，2026-09-04 移入主线）**：
自采 `up_packet_ratio` 在 Camera / Light_T1 / Light_XM / Sensor 的 **100%** 窗口里精确为 0，Socket **100%** 窗口 > 0
（六轮全部如此；`up_len_std` 100% 为零）；成因是方向判定用 `DA == BSSID` 判上行，而 802.11 上行数据帧（ToDS=1）的
`wlan.da` 是 AP 之外的最终目的地址、不等于 BSSID，故四类的上行帧全落进 `other`（`other_packet_ratio` 0.26–0.40），
只有 Socket（其上行恰以 AP 为目的）被识别。**这使 7 列 `up_*` 成为近乎完美的 Socket 检测器**——Socket F1 恒为 1.000
至少部分由此造成。Socket 在流量形状上也确有差异（10 s 窗包数中位 61 vs 21–39、`len_mean` 161 vs 194–214、`burst_count` 10 vs 4–6），
故去掉方向族后大概率仍高，但「免疫」这一格**须去掉 `up_*` 重测才能作签名引用**；UNSW 侧免疫（Dropcam）不受此影响
（网关侧方向由 IP 判定，同族恒零占比 0.005）。修正方向规则（上行 = `wlan.ra == BSSID` 或 `TA == 设备 MAC`）属**重抽特征**而非重采集，可做，但会改动冻结特征定义、须另立协议。三种权重分配全落在最佳基模型附近
（`meta_soft_cls` 三任务均值 −0.0058），只有加跨类项的那档塌到 **−0.1741** → 是**映射**不是权重。
有符号类对矩阵：五个簇内类对**全部净负**，害益比 4.2:1 到 12.1:1（199 次救回真实存在但被压倒）。
`m_src → 元层损伤率` **+0.494**，`m_src → 基模型错误率` **−0.253**。

**模式三 · 元层·仲裁（探索性）**：`|S|=1` 六任务 gap 均值 −0.0571，损失几乎全在分歧窗口，
而 `m_src_max` 在那里**精确为 0**（30/30 个 `|S|=1` 任务）。

**关键：模式一与模式二不相关**（`auc_tgt ↔ m_src_max` −0.153、↔ `harm_max` −0.212，n=35）。
原因是**它们消耗不同的窗口**——模式一先扣掉窗口，模式二只能作用在剩下的：

```
              组合数  目标AUC  基模型错误率  元层损伤率  基共识正确占比
边界保持       26    0.9161   0.4356    0.1898    0.4238
边界反转       13    0.1770   0.6604    0.1100    0.2397
```

所以是**误差预算里的先后关系**，不是两个独立现象。

## 4. 统一形式：伤害 = 强度 × 反转

两个层面上各自实测到同一形态：

```
伤害  =  强度        ×  反转
        源域可测        源域不可见

层面一（特征/基）  rssi 在源域逐类对判别力强（|d_src| 均值 0.1029），方向反转
                   多变量边界 0.9877 → 0.0001（不是掉到 0.5，是掉到 0）
层面二（元层）     m_src 强度 0.1323，其中 69% 在源域是有益的
                   同一映射在目标域以 0.1209 的比例造成伤害
                   开火率几乎不变（0.1323 → 0.1209），变的只有对错
```

**跨域保率、反号。** 两个层面都说：失效是**符号反转**而非幅度衰减。

支撑这一点的两组对照：

```
特征层面   loss（幅度流失）失败：rssi 均值 −0.0177（方向还相反）
           flip（符号反转）有效：rssi 反转率 0.2628，为 transferable-59 的 3.6 倍
元层层面   f_ji_drift（错配幅度）+0.339
           f_ji_src（强度）      +0.593
           m_src（元层自身强度） +0.798，控制它后 f_ji_src 只剩 +0.064
```

**反转的几何形态：排列，不是平移（2026-09-04 补；分三个证据等级）**

- **平移假说已被冻结结果否定**：CORAL / SA（`⓪″`，`DA_DOES_NOT_HELP`，−0.0365 / −0.0893）专修分布平移而失效。可直接进正文。
- **排列图像有两个探索性证据**（未冻结，进正文前须随协议重算）：(i) 上表多变量边界 0.9877 → 0.0001——AUC 趋近 0 是**系统性反向**，
  不是趋近 0.5 的噪声；(ii) 逐列检查（`results/two_channel_20260903/rssi_permutation_*_posthoc.csv`，纯排序 AUC 不拟合）：
  源域强判别（|AUC−0.5| ≥ 0.2）的 60 个（类对 × rssi 列）到目标域 **翻转 18 / 保留 10 / 摧毁 32**；逐类 `rssi_p50` 中位数

  ```
             R2      R3      R4
  Light_T1  −50.0   −45.7   −47.0
  Light_XM  −50.8   −51.7   −45.7
  Sensor    −45.0   −50.7   −46.0
  ```

  每轮都有**一个**类比另两个远约 5 dB，但**是哪个类逐轮换**（R2 Sensor、R3 Light_T1、R4 Light_XM 且只差 1 dB → R4 域内无 rssi 结构，
  R4 也是 IID 最低的一轮 0.8756）。这不是整体平移，是类间排列——任何无监督居中/对齐都修不了，从数据侧解释了 ⓪″ 的失效。
- **措辞限定**：三个轮次说不出「随机」；能说的是**方向从源域测不出**（§5），且类间差是真的、差在谁身上是轮次特有的。

**两个可证伪推论（未测）**：对 rssi 单族做 CORAL 应同样失效；按轮次居中 rssi 不应降低反转率。

**对方法的含义**：删族之外理论只剩一个正向杠杆——用不反转的 59 列作锚给目标窗口伪标签、按伪标签重估 rssi 类条件分布（**转导式**，需目标无标签窗口）。
但上面的数给它划了上界：可修的只有翻转的 30%、且只在目标域内有结构时（R2/R3，非 R4）；rssi 全部域内价值 `ΔJOINT` = 0.04 是硬顶。
**预期 ≤ +0.04、目标依赖**——价值在于把「删一族」变成「重标定一族」这一正向叙事，不在效应量。未立协议。

## 5. 为什么 CPD 与 EC-MDM 失败：函数形式错了

```
CPD_y     行归一化混淆矩阵的漂移量     测「变了多少」   形式对（矩阵、类对分辨），算在 RF 上、无符号
EC-MDM    源元层与 oracle 目标元层之差  测「差多少」     有元层、C 级类条件，但要 oracle 标签、无符号
```

两个都是**幅度/差值**。而两个独立层面都显示幅度是较弱的形式。
**所以它们不是测了个不存在的东西，是把乘积的两个因子都错过了。**

这也解释了项目最大的挫折——「预警量能预测会不会发生，不能预测掉多少分」
（可分性 → 推翻率 −0.753，可分性 → `gap_H` 只有 +0.123）：**源域诊断只看得见强度，看不见反转。**
要预测幅度必须知道反转，而反转需要目标标签。

**UNSW 提供了这条论断的配对实证（2026-09-04 补记；事后解读，非预注册，不改任何判定；
同日上午修订——初版误用了 §7 一个复现不出的分母，披露见本段末）**：
`UNSW-META-MISMATCH` 落**分支 C**（`MECHANISM_NOT_EXTERNALLY_REPLICATED`；四条签名中
①定位 2/3、③系数 0/3、④regime 2/3 失败，②免疫 3/3 通过；幅度 `mean_abs_gap_H` = 0.0099
落在预注册区间 [0.03, 0.20] 之外）。但**失败的形态恰好是本节论断的直接证据**。

四格分解，两侧**同一定义**（三基模型一致 = 共识；共识正确且 stacking 改判 = 破坏；共识错误且 stacking 改对 = 救回；
共识错误且 stacking 改成**另一个**错误 = 换错法），纯聚合、不拟合，产物在盘：
自采 `results/g0_environment_grid/fourcell_posthoc_self.csv`（固定困难簇 {Light_T1, Light_XM, Sensor}），
UNSW `results/unsw_meta_mismatch_20260902/fourcell_posthoc.csv`（Belkin 对）。两侧 `broken` 分别与 §3 的
1149/1472 和登记的 `n_overridden` 507/101/25 **逐位对账一致**。**只比 `|S|=2` 的任务**
（UNSW 三任务都是 2 源日 → 1 目标日，OOF 同样退化为 2 折；自采 `|S|=1` 任务元层几乎不开火：破坏 3 / 1907）：

```
困难簇，|S|=2             共识正确   破坏   共识错误   救回   换错法    净    破坏率   救回率   破坏:救回
自采 full94（3 任务）       1472   1149     1049     199     592   −950   0.7806   0.1897    5.8 : 1
UNSW（3 任务）             4900    633     4358     656      23    +23   0.1292   0.1505    1.0 : 1
UNSW 09-23+09-30→10-12     1710    507     1236     518       8    +11   0.2965   0.4191    1.0 : 1
```

读法按本节的乘积形式：**开火频率是强度，破坏:救回是反转。**自采 = 高强度 × 强反转
（78% 的正确共识被改错；每破坏 5.8 个正确共识只救回 1 个错误共识）；UNSW = 中等强度 × 零反转
（13–30% 被改掉，改对与改错相抵）。`换错法` 592 vs 23 是「无差别开火」这一行为本身的对照。
**UNSW 是一个域内就更难的困难簇（域内 F1 0.53 vs 自采困难簇域内 0.73–0.99）、元层在开火、却零伤害的实例**——
所以困难本身不充分，映射方向才决定伤害。这把本节原本只由相关系数支撑的论断

## 6. 通过四条要求的诊断量

一个够格的预警量要同时满足：①不需目标标签 ②含元层 ③类对分辨 ④有符号。
历史三个候选各缺不同的：可分性缺 ②③④，`CPD_y` 缺 ①②④，EC-MDM 缺 ①④。

**融合量四条全过**（今天找到的）。EC-MDM 的 oracle 需求只在 `F`（目标重拟合元层）那一半，
`S`（源域拟合元层）零目标标签就在 `model.joblib` 里；给 `S` 加上类对分辨与符号即可：

```
m_src[i→j]       基共识为 i 的源域 OOF 窗口中，元模型改判为 j 的比例      映射强度
rescue_src[i→j]  其中「共识 i 错、真值 j、元模型改对」的比例              源域内有益
break_src[i→j]   其中「共识 i 对、元模型改成 j」的比例                    源域内就有害
```

对目标域逐类对伤害：`rescue_src` +0.808、`m_src` +0.798、`break_src` +0.777。

**第三种模式的诊断（仲裁）必须嵌套，否则整体失效**：

| 版本 | Spearman → 目标域分歧组 Δ错误 | 触发 | 命中 | 漏报 |
|---|---:|---:|---:|---:|
| 样本内（`final_estimator_` 作用于自身拟合过的 OOF 行） | **−0.219** | 0/9 | 0 | 7 |
| 嵌套（样本外） | **+0.692** | 7/9 | 6 | 1 |

只算有害侧（不减去有益侧）+0.051，**无信号**——必须用有符号净值。
两个元层通道的信息需求不同：**映射通道需 `|S|>=2`**（单轮次源域 OOF 里不存在跨轮次混淆）；
**仲裁通道 `|S|=1` 也能测**（它测的是元层过拟合，不需要跨轮次位移）。

## 9. 流程：两段制不是工程妥协，是分解的直接后果

```
提议阶段   用源域可测的强度识别暴露        m_src / net_dis_src / 逐类对边界判别力
接受阶段   用历史有标签轮次估计反转率      内层 LORO（|S|>=2）/ 嵌套源域 OOF（|S|=1）
```

因为「伤害 = 强度 × 反转」，第一个因子源域可得、第二个只能从历史证据估。
两个坐标都改成这个形式之后，流程在其所依据的证据上**按构造单调**——
任何一步都不会被接受，除非它在该证据上改善跨轮次 macro-F1。

**所以「只要不在（本移动集合下的）局部最优，应用它可能改善；若已在，它什么都不做」是构造上成立的。**
三处必须同时声明的边界：

1. 「局部最优」相对于**移动集合**（10 个族最多删 3 个 + 堆叠/不堆叠），不是无条件的局部最优。
2. 单调**只在历史证据上**成立，不保证迁移到未见新环境（R5/R6/R7 就是反例档）。
3. 贪心不等于集合内最优——175 个配置的穷举格（约 11 小时）才能判定，另立协议。

**唯一优化目标是跨轮次 macro-F1**；同轮次（IID）只作护栏与天花板参照，不进判据——
部署形态是训一次跑后续轮次，从不在同轮次 regime 内运行，所以那不是权衡。

**使用条件**：历史 1 个环境时坐标 1 与 `m_src` 触发器不可用（且坐标 1 在该档最危险，
98% 的代理量损失集中在 `|S|=1`，最差 −0.2951，而 `|S|=2` 最差仅 −0.0175）；
`net_dis_src` 触发器可用。历史 ≥2 个环境才完整可用。环境越多元层损伤自身也在衰减
（`|S|=2` gap_H −0.1245 → `|S|=3` −0.0805）。
