## 1. 为什么需要确证测试

C1/C2/C4 的证据是**观测性**的，可以在同一批数据上反复审计而不失效。
C3 不同：它断言一个**干预**有效，而这个干预的形态在本项目里被改过多次
（掩族 → 掩族+换模型 → 加时长 → 分层判决 → 因果概率平滑 → 因果特征聚合）。
每一次改动都用同一批 outer 天（`16-10-11`/`16-10-12`）量增益，
**这批天已被反复看过，不再是干净的测试集**。

因此保留了 16 天从未参与任何选择的数据，用于一次性确证。

## 2. 被确证的断言（【已改写】，改写发生在读保留集之前）

原表述："两段式方法（时间平滑 + 定点逐对修复 + 不伤闸门）提升跨环境 macro-F1。"

**改写理由**（2026-09-05，`causal_agg2.py`，未用保留集）：
第一段的正确形态是**因果特征聚合**（在窗 n 用 `[n−k+1, n]` 的原始包重建特征），
不是概率平均。换成正确形态后，UNSW 跨天 macro-F1 `0.8027 → 0.9995`（k=10，100s 证据），
残余 10 个错误里 9 个是 `BelkinWemoMotion|BelkinWemoSwitch`——
**而 Belkin 那对正是第二段此前在 UNSW 上的全部战果**（在位者 0.5489 → 0.075 端到端增益）。
即：**第一段吃掉了第二段在 UNSW 上的作用面**。继续按原表述确证会得出误导性结论。

改写后的断言，三条独立可判、按重要性排序：

| | 断言 | 判据 |
|---|---|---|
| **C3a** | 粒度饱和曲线在留出天上复现，且**饱和在 1.0 附近** —— UNSW 属方差型 | 曲线单调升至 ≥0.99；k=1 与 k=10 的差 ≥0.15 |
| **C3b** | 诊断**事前**预测了第一段够用：第二段在方差型上无作用面，闸门应**拒绝放行** | 第二段过闸对数 ≤1；端到端 \|Δ\| < 0.005 |
| **C3c** | 闸门的不伤性质成立：无论放行与否，端到端不下降 | Δ(第二段) ≥ −0.002 |

**C3b 是本测试最关键的一条，且是"预测无效"而非"预测有效"。**
方法的价值主张因此从"能提多少"改成"**能事前判断该不该出手，且不出手时不赔**"——
这与 [[cic-mechanism-fires-in-wrong-place]] / [[cic-label-space-was-wrong]] 上
"看过之后明确拒绝" 的表述一致，也是 C2 诊断的直接兑现。

**证伪条件（写清楚才算预登记）**：
- 若曲线在留出天上饱和在 0.9 以下 → C3a 假，UNSW 并非纯方差型，C2 的两型划分需修
- 若第二段在留出天上放行 ≥3 对且端到端 ≥ +0.01 → C3b 假，诊断没预测对（**方法反而更强，但诊断的主张塌了**）
- 若端到端 Δ < −0.002 → C3c 假，不伤闸门失效，这是**否决级**结果

## 3. 主判据（唯一，事前指定）

## 5. 成功判据（事前）

## 8. 修正 2（2026-09-05 晚，仍在读保留集之前）

**触发**：§6 步骤 3 的跑通验证（选参天 `16-09-30`，协议明确允许调试）暴露
**闸门本身的记账缺陷**，不是实现 bug 而是方法缺陷。

```python
Dm = sel & np.isin(yu,[i,j])     # 闸门【只在真类∈{i,j} 的窗上】量收益
pred[sel] = np.where(...)        # 却【对整个区施加】
```

R3 区含真类是第三类的窗。若模型正靠第三类判对（`top1 = 第三类 = 真类`），
翻成 i 或 j 就把对的改错了 —— **而闸门看不见这部分伤害**。

### 实测（`gate_diag.py` 选参天 + `cic_region_check.py` CIC 已烧天）

```
UNSW 选参天  Belkin 对    R3      只算{i,j} 0.4244→0.6031 (+0.18)  旧闸门【放行】
                                  整区     0.5971→0.4206 (−0.18)  新闸门【拒绝】
                                  端到端   0.8966→0.8880 (−0.0085)     实际【跌】
                          R3∩R1   整区     0.4244→0.6031 (+0.18)  放行
                                  端到端   0.8966→0.9323 (+0.0357)     实际【涨】
```

**整区记账后，两个数据集 16 个案例中放行/拒绝与端到端符号【零分歧】。**

### 修正 1 —— 整区记账（必要且充分）

在位者与配置必须在**闸门实际作用的全部窗**上量。代码上把作用集合与记账集合
**写成同一个变量**，不允许出现 `sel` 与 `Dm` 两个名字。

### 修正 2 —— 区进入搜索空间：`区 ∈ {R2, R3∩R1, R3}` 逐对选

`R3∩R1`（只在 `top1∈{i,j}` 处施加）**不能**作为全局区定义：CIC 上
`GlobeLamp|GosundSocket` 的 R3∩R1 区里**真类属于该对的窗是 0 个** ——
凡真类属于该对的窗，模型 top1 都是**第三类**，从来不是对内另一个。
这是"确信地判错"最极端的形态：模型不是把两者弄混，是把两者都映到别处。

而最优区**因对而异**且差距很大（Belkin：R3 −0.0085 vs R3∩R1 +0.0357；
GlobeLamp|GosundSocket：R3 +0.0163 vs R3∩R1 0.0000）。
区与掩码、模型是同一类配置项，**而"由结构导出配置"正是本方法的本体**，
故区进入搜索空间，由整区记账的闸门把关。

### C3b 改写为 C3b′

原 C3b（"第二段过闸 ≤1 对、|Δ|<0.005，**预测无效**"）**撤回**：
区进搜索后选参天上 Belkin 那对给 +0.0357，预测无效已不成立。

**C3b′（新）**：闸门在选参天的判决，其**符号**在留出天上复现 ——
```
过闸的每一对，在留出天的【整区】Δ 必须仍为正（符号翻转对数 = 0）
且端到端 Δ > 0
选参天先验：Δ ≈ +0.03（由 Belkin 那对支配）
```
这才是论文实际主张的"不伤"性质，且可证伪。C3a / C3c 不变。

### 诚实声明

**C3b 在一天内被改写两次**，两次都由选参天/已烧天的证据驱动、都未用保留集，
程序上合法。但**反复改写削弱了预登记的价值**：一个上午还预测"无效"、
下午改成预测"+0.03"的断言，不足以承担论文的主结论。

相较之下 **C3a（粒度饱和曲线 / 两型难度）整日未变**。
⇒ **论文的承重结论应是 C3a 与 C1/C2/C4，第二段作为"能事前判断并安全出手"的补充。**
保留集这一次运行是唯一裁判。
